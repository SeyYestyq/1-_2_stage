# Карта объектов конфигурации

Модуль «Ядро и конструктор видов» · ветка `angelina` · состояние на 18.11.2026.
Владелец объекта — тот, кто меняет его реквизиты, формы, модули и макеты. Остальные пользуются
объектом через контракты и данные. Правило: один объект — один разработчик (модульный план, раздел 1).

## Статусы в таблице

| Статус | Значение |
|---|---|
| описано | объект и его реквизиты зафиксированы в `spec/metadata.json` |
| описано + контракт | к объекту дополнительно описан контракт функций в `spec/contracts.md` |
| оболочка | объект создаётся в каркасе пустым (реквизиты, формы или модули с областями), наполняет владелец |
| не описано | объект нужен по модели данных, но в спецификации отсутствует — открытый вопрос |

**Важно:** статус «описано» означает, что объект есть и в `spec/metadata.json`, и файлом в XML-выгрузке
репозитория (`Enums/`, `Catalogs/`, `Documents/`, `InformationRegisters/`, ...). Выгрузку собирает
`tools/gen_config.py`, проверяет `tools/check_config.py`. «Оболочка (создаёт Ангелина)» — объект создан
пустым: файл есть, реквизиты или формы наполняет владелец в своей ветке. В платформу выгрузка не
загружалась (платформы 1С на машине нет) — порядок загрузки в `README.md`.

## 2. Оболочки чужих объектов

Оболочки создаёт Ангелина в ветке `angelina`, потому что новый объект меняет корень конфигурации.
Наполняет объект владелец — в своей ветке. Список того, что Ангелина создаёт «за других»:

| Оболочка | Для кого | Что внутри пустое |
|---|---|---|
| ДокументСЭД.ФормаДокумента | Денис | форма без элементов и модуля |
| ДокументСЭД.ФормаСписка | Денис | форма без списка и отборов |
| ВидыДокументов.ФормаМастер | Денис | форма без страниц |
| Общая форма МоиСогласования | Денис | форма без списка |
| Общий модуль ДинамическиеФормы | Денис | модуль с областями, без кода |
| Элементы стиля (7 имён) | Денис | значения-заглушки |
| Общий модуль Согласование | Максим | модуль с областями, без кода |
| Перечисления РешенияСогласования, СобытияСогласования | Максим | значения из модели данных |
| Регистр ИсторияСогласования | Максим | измерения и ресурсы по модели данных |
| Общий макет ПечатнаяФормаДокумента | Юрий | пустой макет |
| Общие модули ПечатьДокументов, Уведомления, ИнтеграцияMAX | Юрий | модули с областями |
| Общая форма НастройкиПочты | Юрий | форма без реквизитов |
| Регистры ЖурналУведомлений, ПользователиMAX | Юрий | измерения и ресурсы по модели данных |
| Константы (8) | Юрий | значения не заданы |
| Регламентные задания (2) | Юрий | не настроены |
| Общий модуль ТестовыеДанные | Дамир | модуль с областями |

Правило: Ангелина создаёт оболочку и не наполняет её. Если владельцу нужен новый реквизит в объекте
Ангелины (например, «Срок этапа» Максиму) — заявка в отчёте или в чат, правка в ветке `angelina`.
