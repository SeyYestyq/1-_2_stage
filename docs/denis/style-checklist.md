# Элементы стиля и чек-лист форм

Целевая версия — 8.3.24 из спецификации репозитория; решение капитана о версии
не подменяется этим выбором. Палитра задаётся в `spec/metadata.json.styleItems`,
метаданные в `StyleItems` синхронизируются генератором. Формы используют ссылки
`ЦветаСтиля`, HTML получает цвета через один адаптер `CSSЦвет`.

| Элемент | Значение | Назначение |
|---|---|---|
| СтатусЧерновик | #525252 | Черновик и ожидающие этапы |
| СтатусНаСогласовании | #1457A8 | Текущий этап |
| СтатусСогласован | #176B38 | Пройденный этап |
| СтатусОтклонен | #B42318 | Отказ |
| СтатусНаДоработке | #9A4D00 | Доработка |
| АкцентПродукта | #FFDD00 | Основное действие |
| ФонТаймлайна | #F5F6F8 | Фон маршрута |

Это локальный чек-лист для команды, не утверждённый стандарт организаторов.
