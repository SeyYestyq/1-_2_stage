# Запуск проверок в установленной 1С

На машине разработки 1С отсутствует. Скрипт подготовлен и проверен тестами
обработки результатов; с настоящим Конфигуратором он здесь ещё не запускался.

## Дистрибутив

Целевая учебная платформа: **1С 8.5.1.1150, Linux 64-bit**.
[Официальная страница получения](https://online.1c.ru/catalog/programs/program/36179915/)
требует анкету (ФИО, email) и принятие лицензионного соглашения. Анкета от имени
пользователя не отправлялась. Для продолжения нужен уже полученный дистрибутив
или ссылка на него.

## Загрузка и проверка

После установки выполнить из корня репозитория:

```sh
python3 tools/check_in_1c.py --platform /путь/к/1cv8t
```

Можно задать **новый или пустой** каталог результатов:

```sh
python3 tools/check_in_1c.py --platform /путь/к/1cv8t --workspace /tmp/docroute-1c-check
```

Скрипт последовательно создаёт отдельную файловую ИБ, загружает `ДокМаршрут/`,
обновляет конфигурацию БД и вызывает `/CheckConfig -ThinClient -WebClient -Server`.
Он не запускает Предприятие, не создаёт демо-данные, не настраивает SMTP и не отправляет письма.
Рабочие базы и окна других процессов не используются. В непустой каталог скрипт не пишет.

В каталоге результата остаются `report.json`, логи и файлы `/DumpResult` по этапам.
Ненулевой код процесса **или** `/DumpResult` останавливает дальнейшие этапы.
Отсутствующий файл результата также считается ошибкой, даже при exit code 0.
Таймаут одного этапа — 300 секунд (`--timeout`); при таймауте останавливается
только созданный этим запуском процесс и его дочерняя группа.

Подготовить план команд без запуска платформы:

```sh
python3 tools/check_in_1c.py --prepare-only
```

Такой отчёт имеет статус `prepared_not_run` и не подтверждает проверку 1С.
Даже успешный `/CheckConfig` не заменяет [приёмку форм](acceptance.md)
и [проверку мастера и страницы](wizard-home.md).

## Исполняемые тесты преобразования значений без 1С

[OneScript](https://github.com/EvilBeaver/OneScript) выполняет отдельные чистые
функции BSL, извлечённые из исходников проекта без изменения их тела:

```sh
python3 tools/run_bsl_value_tests.py --oscript /путь/к/oscript
```

Для поставки OneScript с `oscript.dll` и установленным .NET:

```sh
python3 tools/run_bsl_value_tests.py --oscript /путь/к/oscript.dll
```

Выполнено на OneScript 2.2.0 / .NET 8: 15 проверок чисел, дат и имён файлов.
Это исполнение функций в совместимой среде, а не запуск управляемых форм,
метаданных, запросов или движка согласования 1С.
