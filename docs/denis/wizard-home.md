# Мастер вида и начальная страница

Реализовано в ветке `denis` поверх интегрированной сборки Дамира. Платформа
здесь не установлена: сценарии ниже требуют ручной приёмки в тестовой 1С 8.5.1.

## Вход в интерфейс

- При начале работы приложения открывается общая форма «Начальная страница».
- Вернуться к ней можно кнопкой «Начальная страница» в списке документов.
- «Создать вид в мастере» на странице и «Создать в мастере» в списке видов
  открывают новую форму. В карточке черновика есть «Продолжить в мастере».
- Опубликованные виды редактируются обычной карточкой, мастер их не открывает.

## Четыре шага

1. **Основное**: наименование, категория, префикс, описание. «Далее» проверяет
   обязательные поля и сохраняет черновик.
2. **Поля**: заголовок, тип, обязательность и порядок. Порядок и технический
   идентификатор заполняются автоматически. Идентификатор скрыт; новые поля
   получают уникальные значения, чтобы не наследовать список удалённого поля.
   Для «Выбора из списка» кнопка «Значения списка» сохраняет вид и открывает
   значения с отбором по владельцу и полю. Нужно минимум два значения.
3. **Маршрут**: минимум два этапа. Номера при записи последовательно
   пересчитываются по порядку строк; финальная проверка требует двух разных
   согласующих и не допускает одного сотрудника подряд.
4. **Проверка**: выводятся все сообщения существующего конструктора видов.
   При ошибках публикация недоступна. Можно вернуться, исправить данные и
   выполнить проверку снова. Публикация повторно вызывает проверку ядра.

«Назад» сохраняет введённые данные в форме. «Сохранить черновик» доступно
на любом шаге; закрытый черновик можно продолжить через его карточку.
«Предпросмотр формы» показывает те же редакторы, что реальный документ,
без записи документа в ИБ. Ядро конструктора и формат хранения не менялись.

## Персональная страница

- «Мои документы» — документы, где сотрудник является автором **или** ответственным.
- «Мои согласования» — статус «На согласовании» и текущий согласующий равен сотруднику.
- Помеченные на удаление документы исключены из персональных таблиц и счётчиков.
- Счётчики считаются по всем персональным документам, независимо от лимита таблицы.
- В таблицах первые 20 документов; кнопки открывают полные персональные списки.
- Без единственной привязки пользователя ИБ к сотруднику персональные данные пусты
  и показано пояснение. Это также применяется к персональным отборам списка документов.
- Кнопка «Обновить» перечитывает данные. После закрытия карточки документа или
  мастера, открытых со страницы, данные также обновляются.

## Ручная приёмка

Все пункты пока не выполнены в платформе.

- [ ] Пустая ИБ открывает страницу без ошибок; создание вида и документа доступно.
- [ ] Пройти все четыре шага с новым договорным видом, тремя типами полей,
      списком из двух значений и двумя разными согласующими. Опубликовать.
- [ ] С пустым именем/категорией/префиксом «Далее» остаётся на первом шаге,
      сообщения связаны с полями. Пустые поля/маршрут не дают пройти соответствующий шаг.
- [ ] «Назад» и повторный переход не стирают поля. Сохранить и закрыть черновик,
      продолжить из обычной карточки, проверить старые значения списка.
- [ ] Скопировать/удалить строку поля, затем создать новую: идентификаторы не повторяются,
      значения удалённого поля не оказываются значениями нового.
- [ ] Удалить этап, добавить этап, записать: номера последовательные; один сотрудник
      на двух этапах блокирует публикацию. Исправление и повторная проверка её разрешают.
- [ ] Опубликованный вид доступен в выборе документа, предпросмотр не создаёт документ.
- [ ] Два пользователя со своими документами/согласованиями видят разные списки.
- [ ] Сотрудник является одновременно автором и ответственным: документ считается один раз.
- [ ] Нет привязки или логин продублирован: пустые персональные списки и счётчики,
      пояснение; режимы полного персонального списка не превращаются в общий список.
- [ ] 21 персональный документ: счётчик 21, таблица 20, полный список содержит 21.
- [ ] Помеченный на удаление документ не попадает в персональные данные.
- [ ] Закрытие документа после сохранения/решения обновляет счётчики страницы;
      отдельное «Обновить» отражает изменения, сделанные в другом окне.
- [ ] Проверить клавиатуру, экран 1280×768, тонкий и веб-клиент. Новичок вне команды
      создаёт вид без устных подсказок.
