# Интерфейс Дениса: текущая поставка

Рабочая выгрузка: **`ДокМаршрут/Configuration.xml`**. Ветка `denis` включает
сборку Дамира `d36e780` и изменения интерфейса поверх неё. Корневой каркас из
`angelina` заменён этой сборкой; первая реализация остаётся в истории (`15cbbe5`).
Ветка `damir` не изменяется. По её README сборка проверялась автором на учебной
1С 8.5.1.1150. На этой машине платформы нет, новый интерфейс в ней не запускался.

## Что изменено относительно damir

- Отдельные редакторы полей по `Порядок`: строка, число, дата, выбор из списка.
- Значения по-прежнему хранятся в `ЗначенияПолей.ЗначениеСтрока`: контракты
  согласования, печати и уведомлений не меняются. Обновляются только изменённые
  видимые поля. Скрытые и некорректные старые значения при открытии не стираются.
- Числа и даты преобразуются при явном изменении; повреждённое старое значение
  остаётся текстовым редактором для исправления вместо автоматического обнуления.
- Все ошибки формы выдаются сообщениями с привязкой к конкретным полям.
  Неполный черновик сохраняется, обязательность проверяется при отправке.
- Сначала выбирается категория, затем готовый непомеченный на удаление вид этой
  категории. Смена категории/вида требует подтверждения очистки полей.
- Предпросмотр сохранённого вида через ту же форму документа: режим чтения,
  запись блокируется на клиенте и сервере, документ в ИБ не создаётся.
- Комментарий отказа/возврата вводится асинхронно; отмена диалога не даёт решения.
- После отказа/отмены записи отправка на согласование не продолжается.
- При очистке ответственного очищается прежний руководитель.
- «Мои задачи» сохраняет выбранный фильтр статуса; при исчезновении привязки
  сотрудника запрос не расширяется до общего списка.

Изменены общий модуль динамических форм и файлы форм документа,
списка документов и вида. Добавлены мастер, общая начальная страница и
её открытие из модуля управляемого приложения; в метаданных зарегистрированы
только эти формы. Движок, печать, уведомления, их метаданные и стили
из сборки Дамира сохранены без изменений. Отдельная форма `МоиСогласования`
заменена существующим режимом «Мои задачи» списка документов.

## Проверки

```
python3 tools/check_dump.py
PYTHONDONTWRITEBYTECODE=1 python3 -m unittest discover -s tools/tests -v
```

Проверка структуры: 74 XML, 138 UUID, связи обработчиков и экспортных функций.
Девять регрессионных тестов проверки интеграции. Все 20 BSL-модулей разобраны
`bsl-parser 0.29.0` / `antlr4 0.2.0` на Java 17 без синтаксических ошибок.
Это не компиляция 1С и не проверка пользовательских сценариев в платформе.
