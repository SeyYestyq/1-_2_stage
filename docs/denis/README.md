# Интерфейс Дениса

Ветка `denis`, база — `angelina`, коммит `c0696f6`.
Платформа целевая: 8.3.24, управляемые формы. Код интерфейса создаёт элементы
программно: каркас XML сохраняет реквизиты и события, общий модуль — построение.

## Область изменений

Только формы документа и списка `ДокументСЭД`, `МоиСогласования`,
`ДинамическиеФормы`, семь элементов стиля и их значения в `spec/metadata.json`.
Метаданные документа, ядро конструктора, движок и печать не изменяются.
В генератор внесена небольшая правка: готовые тела общих форм сохраняются
при повторной генерации и при экспорте `--out`; на неё добавлены два регрессионных теста.

## Зависимости интеграции

В исходной ветке `Согласование` и `ПечатьДокументов` — пустые оболочки.
Поэтому отправка, решение, возврат и печать отключены; пояснение видно в карточке.
Статусы интерфейс самостоятельно не переводит. Подключение этих действий —
в `ДинамическиеФормы.ДоступныеДействия()` и обработчиках формы после получения
подтверждённых экспортных функций владельцев. Не следует включать кнопки только
по совпадению пользователя: окончательные права и изменение статуса проверяет сервер.

Список и история читают существующие реквизиты и регистр без изменения данных.
«Мои согласования» определяется по имени пользователя ИБ из `Сотрудники.Пользователь`;
при отсутствии или неоднозначности привязки список пуст и выводится пояснение.

## Проверка в платформе

Платформа 1С в этой среде не установлена. Проверки XML и синтаксиса BSL не заменяют
загрузку конфигурации и ручную приёмку. Порядок проверки — `acceptance.md`.
Мастер вида, начальная страница и презентация относятся к следующим этапам плана;
их нет в этой поставке.
