# ДокМаршрут (этап 2)

Рабочая XML-выгрузка конфигурации — в каталоге [`ДокМаршрут/`](ДокМаршрут/) (`Configuration.xml` внутри).

Пошаговый запуск на учебной **1С 8.5.1.1150**: [ДокМаршрут/README.md](ДокМаршрут/README.md).

Кратко: пустая ИБ → Конфигуратор → **Загрузить конфигурацию из файлов** → указать папку `ДокМаршрут` → **F7** → Предприятие → «Загрузка демо-данных».

Каталог `bases/` (готовая файловая база) **не нужен** и в репозиторий не входит: каждый поднимает свою пустую базу из выгрузки.

Ветка `denis`: сборка `damir` с типизированными полями и предпросмотром формы.

Описание изменений и проверки: [docs/denis/README.md](docs/denis/README.md).
